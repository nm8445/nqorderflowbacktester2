Bar Vector Feature Equations

NQ Futures Orderflow Backtester — Feature Engine Reference

Overnight HMM — 8 features
FeatureEquationWhat it captures
abs_delta_pct |buy_vol − sell_vol| / total_vol Committed aggression either direction. High = one-sided orderflow regardless of up or down
trend_ratio |close − open| / (high − low) Price efficiency per bar. High = moved purposefully. Low = noisy range with little net displacement
abs_normalized_d_move |net_move| / rolling_σ Move size relative to recent volatility baseline. High = large move relative to what's normal
realized_vol σ(bar_returns) over session Session activity level. High = volatile session with large range per bar
trade_arrival_rate trade_count / session_duration Tape urgency. High = aggressive participation, fast tape, lots of activity
overnight_deceleration slope(2nd half) − slope(1st half) Trend persistence into open. Negative = move slowed (failed auction risk). Positive = sustained commitment
abs_obi_avg mean(|bid_vol − ask_vol| / (bid_vol + ask_vol)) Order book leaning. High = book consistently stacked one side regardless of which direction
autocorr_r1 corr(r_t, r_{t−1}) Return persistence. Positive = directional (returns persist). Negative = mean-reverting (returns reverse)
All 8 features z-score normalized per session before HMM ingestion. Signed features use absolute values — direction is stripped, only magnitude matters for overnight classification.
RTH HMM — 10 base features
FeatureEquationWhat it captures
delta_pct (buy_vol − sell_vol) / total_vol Signed aggression. Positive = buyers in control. Negative = sellers in control
trend_ratio |close − open| / (high − low) Price efficiency per bar — same calculation as overnight version
obi_avg mean((bid_vol − ask_vol) / (bid_vol + ask_vol)) Signed book imbalance. Positive = bid-heavy book. Negative = ask-heavy book
realized_vol σ(bar_returns) over session Session volatility level across RTH window
trade_arrival_rate trade_count / session_duration Tape speed and participation urgency during RTH
delta_acceleration Δ(delta_pct) / Δt Rate of change of aggression. Positive = buying pressure building over time
obi_trend slope(obi over session) Whether book imbalance is increasing or decreasing through the RTH session
vwap_deviation (price − vwap) / vwap_σ Distance from VWAP in std dev units. High = price extended away from fair value
autocorr_r1 corr(r_t, r_{t−1}) Return persistence. Negative in trending (noise on trend). Positive in chop (mean-reverting noise)
normalized_d_move net_move / rolling_σ Signed net move relative to volatility. Positive = up move. Negative = down move
RTH excursion features — 3 added
FeatureEquationWhat it captures
max_excursion_ratio |close − open| / (high − low) Net move as fraction of gross range. High ≈ 1.0 = clean directional trend. Low ≈ 0 = choppy, no net displacement
trend_consistency directional_bars / total_bars Fraction of bars closing in the session direction. High = sustained trend. Low ≈ 0.5 = two-sided auction
drawdown_ratio max_adverse_excursion / |net_move| Largest counter-trend move divided by gross move. Low = no meaningful pullbacks (strong trend). High = ranging or reversing
Excursion features measure session-level price structure — not bar-by-bar averages. They are immune to micro-bar consolidation noise that dilutes the averaged features above. Compute once per session at the aggregation step. RTH pipeline only — do not add to overnight HMM. Guard drawdown_ratio against division by zero when net_move ≈ 0.
