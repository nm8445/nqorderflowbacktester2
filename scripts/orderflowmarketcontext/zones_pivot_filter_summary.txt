Displacement rule
-----------------
After the formation run ends, look at the next 3 bars. The candidate zone is
KEPT only if at least one of those 3 bars closes:
  - support:    close >= zone_high + 0.5 * ATR(14, 5min)
  - resistance: close <= zone_low  - 0.5 * ATR(14, 5min)
Otherwise the candidate is dropped (price stalled in the zone).

Interpretation
--------------
The zones that survived the displacement filter have HIGHER activity per zone
(more touches, more respects) — they're the ones price actually moved away
from and came back to, exactly the "level memory" property we wanted. The raw
filter was capturing a lot of stalling clusters where price was still hovering
in the same range; the pivot filter removes those.

Retune commands
---------------
Stricter (need a bigger move away from zone):
  python scripts\cache_creation_scripts\build_wick_zones.py ^
         --displacement-bars 3 --displacement-atr 1.0 --suffix _pivot_strict

Looser (allow smaller moves):
  python scripts\cache_creation_scripts\build_wick_zones.py ^
         --displacement-bars 5 --displacement-atr 0.3 --suffix _pivot_loose

Then enumerate the new suffix's zones for the same date window:
  python "scripts\orderflowmarketcontext\zones_detail_mar_apr_2026.py" ^
         --suffix _pivot_strict

Higher --displacement-atr  -> fewer, more decisive zones.
Higher --displacement-bars -> allows slower setups to qualify.
