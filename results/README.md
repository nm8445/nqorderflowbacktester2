# Results

Backtest results and optimization outputs.

## Structure

```
results/
├── csv/      # CSV optimization results, trade logs, metrics
└── html/     # Interactive equity curves, charts, calendars
```

## CSV Files

All CSV outputs from backtests and optimizations:
- Walk-forward optimization results
- Monte Carlo simulation results
- Trade logs
- Performance metrics
- Optimization grids

## HTML Files

Interactive visualizations:
- Equity curves
- PnL calendars
- Drawdown charts
- Analysis reports

## Usage

Most scripts save their outputs to these folders automatically.

To view HTML files:
- Double-click to open in browser
- Or use: `start results/html/equity_curve.html`
